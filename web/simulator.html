About UNSW-NB15

The UNSW-NB15 dataset is a comprehensive network intrusion detection dataset created by the Australian Cyber Security Centre (ACSC). It contains modern normal and contemporary attack behaviors.

This simulator generates synthetic network flows based on the UNSW-NB15 patterns, allowing you to test the AI-NIDS detection capabilities against various attack categories including:

  • Fuzzers - Automated random input to discover vulnerabilities
  • Analysis - Port scans, web attacks, spam
  • Backdoors - Stealth pathways to bypass authentication
  • DoS - Denial of Service attacks
  • Exploits - Known vulnerabilities exploitation
  • Generic - Signature-based attacks
  • Reconnaissance - Information gathering
  • Shellcode - Malicious code execution
  • Worms - Self-replicating malware
